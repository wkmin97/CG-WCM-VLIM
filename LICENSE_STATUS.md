# Licensing remains to be confirmed

This preparation draft does not select a new license for the authors' code or data. No third-party code from the reference rice repository was copied into this project.

Before public release, the authors should add an appropriate code license and state the terms for the supplied UAV, field-reference, and processed data. Third-party GEDI and comparison products retain their original attribution and redistribution requirements. Record source-specific terms alongside the final data manifest.

Public visibility alone should not be described as an explicit software/data reuse license. The final license choice should reflect the authors' and data owners' permissions.
